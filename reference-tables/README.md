# Referenztabellen | الجداول المرجعية

Dieser Bereich enthält überprüfte Tabellen und Übersichten, z. B.:
- Phoneminventare und Artikulationsmerkmale;
- morphologische Paradigmen;
- Verb- und Nominalmuster;
- syntaktische Konstruktionen;
- dialektvergleichende Merkmale;
- Terminologie- und Transliterationsübersichten.

Jede Tabelle benötigt Titel, Gegenstandsbereich, Varietät/Register, Quellen und Hinweise auf Vereinfachungen. Eine Tabelle darf sprachliche Variation nicht als Fehlerliste darstellen.
